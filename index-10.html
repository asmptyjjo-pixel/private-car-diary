Private Car Diary 시작하기

GPS 자동화를 사용하려면 이 HTML을 한 번만 GitHub Pages에 올려 HTTPS 웹주소를 만들어야 합니다.

여러 명이 사용해도 한 명만 배포하면 됩니다.
관리자가 한 번 만든 HTTPS 주소를 다른 사용자에게 공유하면 됩니다. 각 사용자의 이름·차량번호·출장기록은 각자의 휴대폰 브라우저에 별도로 저장됩니다.
